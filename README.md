# Data Analyst Portfolio — Tanooja Karri

A responsive personal portfolio website built with HTML and CSS.

## Sections
- Introduction and professional summary
- Education
- Technical skills: SQL, Excel, Python, Tableau and Analytics
- Analytics projects
- Certifications
- Contact links

## Run locally
Open `index.html` in a web browser.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
2. Add your latest resume PDF to this folder and name it `resume.pdf`.
3. Replace the generic GitHub repository links on each project card with the exact repository URL for that project.
4. Confirm all project descriptions and certification details are accurate.

## Deploy
Upload the files to your GitHub portfolio repository, then connect that repository to Vercel or enable GitHub Pages.
